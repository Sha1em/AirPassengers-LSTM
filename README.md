# AirPassengers LSTM Forecasting

This project applies a Long Short-Term Memory (LSTM) neural network to forecast monthly international airline passenger totals from 1949 to 1960.

## Files
- `AirPassengers_LSTM.ipynb`: Main notebook with code and plots.
- `AirPassengers.csv`: Input dataset.
- `requirements.txt`: Python dependencies.

## Model
We used an LSTM model with 12-month windowing and trained it to predict future passenger counts. Results include both train/test predictions and visual plots.

## How to Run
Open the notebook in Google Colab or Jupyter, ensure all packages in `requirements.txt` are installed, and run all cells.
